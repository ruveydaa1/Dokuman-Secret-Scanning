# 2. Secret Scanning Araçları

Secret Scanning, kaynak kodlarda ve depolarda yanlışlıkla paylaşılmış gizli bilgileri tespit etme işlemidir.

Bu işlem için kullanılan araçlardan ikisi Gitleaks ve TruffleHog'dur. Her iki araç da secret tespit edebilir ancak kullandıkları yöntemler, tarama kaynakları ve sundukları özellikler bakımından farklılık gösterir.

### 2.1. Gitleaks

Gitleaks, Git depolarında ve dosyalarda bulunan gizli bilgileri tespit etmek için kullanılan açık kaynaklı bir güvenlik aracıdır.

Temel amacı kaynak kod içerisinde yanlışlıkla paylaşılmış API anahtarları, token'lar, parolalar ve benzeri hassas bilgileri bulmaktır.

Gitleaks, önceden tanımlanmış tespit kurallarından yararlanır. Bu kurallar sayesinde belirli biçimlere sahip değerleri arayabilir. Ayrıca ihtiyaca göre özel kurallar oluşturulabilir.

Gitleaks'in kullanılabildiği bazı alanlar şunlardır:

* Git deposunun geçmişini tarama.
* Belirli dosya veya dizinleri tarama.
* Özel regex kuralları oluşturma.
* CI/CD süreçlerinde otomatik tarama gerçekleştirme.
* Commit öncesinde secret kontrolü yapma.

Örneğin bir geliştirici API anahtarını yanlışlıkla kaynak koda eklediğinde Gitleaks bu değeri tanımlı kurallarla eşleştirerek bir bulgu oluşturabilir.

Gitleaks'in önemli özelliklerinden biri Git geçmişini de tarayabilmesidir. Böylece yalnızca güncel dosyalarda bulunan değil, geçmiş commit'lerde kalmış secret değerleri de tespit edilebilir.

### 2.2. TruffleHog

TruffleHog, kaynak kodlarda ve farklı veri kaynaklarında gizli bilgileri tespit etmek için kullanılan bir güvenlik aracıdır.

Gitleaks gibi Git depolarını tarayabilir. Bunun yanında GitHub, GitLab, dosya sistemleri ve çeşitli bulut kaynakları gibi farklı alanlarda da tarama gerçekleştirebilir.

TruffleHog'un öne çıkan özelliklerinden biri, desteklenen secret türlerinde doğrulama yapabilmesidir.

Örneğin bir Git deposunda AWS erişim anahtarına benzeyen bir değer bulunduğunda TruffleHog, desteklenen doğrulama mekanizmasını kullanarak bu anahtarın servis tarafından kabul edilip edilmediğini kontrol etmeye çalışabilir.

TruffleHog'un öne çıkan kullanım alanları:

* Git depolarında secret taraması.
* Farklı kaynaklardaki gizli bilgilerin aranması.
* Desteklenen anahtar türlerinin doğrulanması.
* Özel secret tespit kuralları oluşturulması.
* CI/CD süreçlerine entegre edilerek otomatik tarama yapılması.

TruffleHog'un doğrulama özelliği önemli bir avantajdır. Çünkü yalnızca bir anahtar formatına benzeyen değerleri bulmak yerine, desteklenen durumlarda bulunan değerin gerçekten kullanılabilir olup olmadığı hakkında da bilgi sağlayabilir.

**Genel değerlendirme:**

Gitleaks, özellikle Git depolarının taranması ve kurallara dayalı secret tespiti için kullanışlıdır.

İki araç da farklı ihtiyaçlara cevap verebilir. Bu nedenle birinin diğerinin tamamen yerine geçmesi gerektiği düşünülmemelidir.
